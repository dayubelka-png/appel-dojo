Installer l'Appel du dojo

À faire une seule fois, sur un ordinateur puis sur la tablette (environ 30 minutes). Ensuite, la page fonctionne seule : elle lit ton fichier Excel sur OneDrive et le met à jour à chaque « Valider l'appel ».

Étape 1Créer l'espace Microsoft pour développeurs

Pourquoi : Microsoft exige un « annuaire » pour autoriser une page à écrire dans OneDrive. Le compte Azure gratuit le crée automatiquement.

  1. Va sur azure.microsoft.com/fr-fr/free et clique sur Commencer gratuitement.
  2. Connecte-toi avec ton compte Microsoft (celui de ton OneDrive convient).
  3. Renseigne ton téléphone et une carte bancaire (crédit ou débit, pas de carte prépayée).
Carte bancaire : elle sert uniquement à vérifier ton identité. Microsoft bloque environ 1 $ puis l'annule ; rien n'est prélevé tant que tu ne passes pas toi-même au paiement à l'utilisation. L'inscription d'une page web comme celle-ci est gratuite.

Étape 2Mettre la page en ligne (GitHub Pages, gratuit)

  1. Crée un compte sur github.com.
  2. Clique sur + › New repository. Nom : appel-dojo, visibilité Public, puis Create repository.
  3. Clique sur uploading an existing file et glisse tous les fichiers de ce dossier : index.html, jszip.min.js, msal-browser.min.js, sw.js, manifest.webmanifest, icon-192.png et icon-512.png. Valide avec Commit changes.
  4. Va dans Settings › Pages. Dans « Branch », choisis main et / (root), puis Save.
  5. Après une à deux minutes, ta page est en ligne à l'adresse https://TON-PSEUDO.github.io/appel-dojo/. Note-la exactement, avec la barre finale.
Confidentialité : le dépôt GitHub ne contient que le code de la page, aucune donnée d'élève. Le fichier Excel reste sur ton OneDrive et sur la tablette.

Étape 3Inscrire la page chez Microsoft

  1. Va sur portal.azure.com, cherche Microsoft Entra ID, puis ouvre Inscriptions d'applications › Nouvelle inscription.
  2. Nom : Appel du dojo.
  3. Types de comptes pris en charge : Comptes Microsoft personnels uniquement.
  4. URI de redirection : plateforme Application monopage (SPA), adresse = celle de l'étape 2, par exemple https://TON-PSEUDO.github.io/appel-dojo/.
  5. Clique sur Inscrire, puis copie l'ID d'application (client) affiché sur la page de l'application (format 1a2b3c4d-…).

Pas besoin de secret ni de réglage d'autorisations : à la première connexion, Microsoft te demandera simplement d'autoriser l'accès à tes fichiers.

Étape 4Installer sur la tablette Android

  1. Ouvre l'adresse de l'étape 2 dans Chrome.
  2. Colle l'ID d'application, puis Continuer. La page affiche l'adresse de redirection attendue : elle doit être identique à celle déclarée à l'étape 3.
  3. Se connecter avec Microsoft, avec le compte qui contient le fichier, puis accepte l'accès aux fichiers.
  4. Recherche « Appel » et touche ton fichier Appel adhérents saison 2026-2027.
  5. Menu ⋮ › Ajouter à l'écran d'accueil (ou Installer l'application). L'icône verte « Appel » s'ouvre ensuite en plein écran.

Au quotidienFaire l'appel

  1. Ouvre l'appli : le cours du jour et la séance du jour sont sélectionnés tout seuls.
  2. Touche les élèves présents (le bouton « Mode tablette » agrandit les cartes sur tout l'écran ; en cours chargé, les étiquettes deviennent des pastilles : rouge = santé, orange = autre info, « i » pour la fiche).
  3. Touche Valider l'appel : le fichier sur OneDrive est relu, les cases du jour sont cochées et le total du jour est mis à jour. Rien d'autre n'est modifié.
Sans réseau au dojo : les coches restent sur la tablette et partent automatiquement dès que le réseau revient (ou à la prochaine ouverture de l'appli).
Fichier modifié sur l'ordinateur entre-temps : la page relit la dernière version et y replace tes coches par nom d'élève et par date, sans écraser les modifications faites ailleurs.
Fichier ouvert dans Excel au même moment : OneDrive peut le verrouiller quelques minutes ; la page te prévient et garde les coches.
Reconnexion : de temps en temps, Microsoft peut redemander de toucher ton compte. Les coches ne sont jamais perdues.
Sécurité : la tablette garde une copie du fichier (dont les informations médicales) ; protège-la par un code de verrouillage.
